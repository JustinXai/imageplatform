AI 图片/视频生成 系统安装教程

基于 ThinkPHP 8.1 · 宝塔面板 · Nginx 环境

前置要求：一台已安装宝塔面板的 Linux 服务器（CentOS 7+ / Ubuntu 20.04+），已绑定域名并解析到服务器 IP。
1
环境要求检查
▼

在开始安装前，请确认服务器满足以下环境要求：

🐘
PHP 版本
≥ 8.1.0
🔌
Web 服务器
Nginx
🗃
数据库
MySQL 5.7+
📄
SG 扩展
SourceGuardian 16
Tips：推荐使用宝塔面板的 PHP 8.1 版本，安装后直接在面板中切换即可。
2
安装 PHP 8.1
▼

在宝塔面板中安装 PHP 8.1 版本：

  • 登录宝塔面板，进入 软件商店 → 运行环境
  • 找到 PHP 8.1，点击 安装
  • 编译安装模式选择 极速安装或编译安装（约 1-2 分钟）
  • 安装完成后，点击 设置 确认版本号

安装完成后，建议安装以下常用扩展（在面板 PHP 设置 → 安装扩展中勾选）：

  • sg16 — 必须安装-脚本加密
  • fileinfo — 文件信息检测
  • redis — 缓存驱动（如使用 Redis）
  • gd / imagick — 图片处理
3
安装 SourceGuardian (SG16) 扩展（如PHP8.1安装的不起作用再使用此步骤）
▼

SG16 扩展用于解密加密的 PHP 业务代码文件，必须安装：

  1. 下载 SourceGuardian Loader：
    https://www.sourceguardian.com/loaders.html
  2. 根据 PHP 版本选择对应的 ixed.8.1.lin（Linux）或 ixed.8.1.win.dll（Windows）
  3. 将文件复制到 PHP 扩展目录（可在 PHP 设置中查看 extension_dir）
  4. 在 PHP 配置文件 php.ini 中添加：extension=ixed.8.1.lin
  5. 重启 PHP-FPM 服务
宝塔面板快速安装命令（Linux） 
# 进入 PHP 8.1 扩展目录
cd /www/server/php/81/lib/php/extensions/no-debug-non-zts-20210902/

# 下载 SG16 Loader（如服务器可直连外网）
wget https://www.sourceguardian.com/loaders/ixed.8.1.lin

# 或上传已下载的 ixed.8.1.lin 文件到此目录
# 然后在 php.ini 末尾添加
echo "extension=ixed.8.1.lin" >> /www/server/php/81/etc/php.ini

# 重启 PHP-FPM
/etc/init.d/php-fpm-81 restart

# 验证扩展已加载
php -m | grep SourceGuardian
4
上传项目文件
▼

将项目源代码上传到服务器：

  • 在宝塔面板中创建网站，填写域名，根目录选择后文将设置的运行目录
  • 使用宝塔 文件管理器 或 FTP/SFTP 工具上传项目文件
5
设置运行目录为 Public
▼

本项目基于 ThinkPHP 8.1 多应用模式，入口文件位于 Public/ 目录，需将网站运行目录指向它：

方法一：宝塔面板设置（推荐）

  • 在宝塔面板 → 网站 → 点击对应域名的 设置
  • 选择 网站目录 标签页
  • 在 运行目录 下拉框中选中 /Public
  • 点击 保存
效果：设置后网站根目录不变（/www/wwwroot/你的网站目录/），但 Nginx 的 document_root 会自动指向 .../Public，用户访问 https://你的域名/ 即可直接进入。
6
配置 Nginx 伪静态规则
▼

在宝塔面板中配置伪静态规则，实现 ThinkPHP 的 URL 重写和上传目录安全保护：

宝塔面板操作：

  • 网站设置 → 伪静态 标签页
  • 选择 ThinkPHP 模板（或选择"自定义"）
  • 将下方规则完整粘贴并保存
nginx 伪静态规则 
location / {
    try_files $uri $uri/ $uri.php$is_args$args;
}

location ~* ^/uploads/.*\.(php|php5|phtml|phar)$ {
    deny all;
}
7
配置数据库并导入
▼

创建数据库并导入初始数据：

  • 宝塔面板 → 数据库 → 添加数据库
  • 填写数据库名称、用户名、密码，字符集选择 utf8mb4
8
配置计划任务（Worker 队列）
▼

图片/视频生成任务通过 Worker 异步队列处理，需要配置计划任务定期触发：

  • 宝塔面板 → 计划任务 → 添加计划任务
  • 任务类型选择 Shell 脚本
  • 执行周期建议 10-60 秒（根据服务器负载调整，推荐设置 30 秒）
  • 脚本内容填写下方命令
Shell 脚本内容 
php81 /www/wwwroot/你的网站目录/worker/generate_worker.php --once
9
最终检查与验证
▼

安装完成后，进行全面检查：

✅ 检查清单

  • PHP 版本是否为 8.1.x（php -v）
  • SourceGuardian 扩展是否加载（php -m | grep SourceGuardian）
  • 网站运行目录是否正确设置为 Public
  • 伪静态规则是否正确配置并生效
  • runtime/ 和 uploads/ 目录是否 755 可写
  • Nginx 是否已重载配置（nginx -s reload）
  • 防火墙是否已放行 443 端口（https 访问）
完成安装！打开浏览器访问 https://你的网站目录/ 即可看到系统首页。如果遇到 502 Bad Gateway，请检查 PHP-FPM 是否运行：/etc/init.d/php-fpm-81 status。PHP-FPM request_terminate_timeout 默认约 100 秒，长耗时任务（如图片生成）已改为 Worker 异步队列模式，不会触发超时。
⚡
快速命令汇总
▼
一键检查脚本 
# 1. 检查 PHP 版本
php -v

# 2. 检查 SG 扩展
php -m | grep -i sourceguardian

# 3. 重启 PHP-FPM
/etc/init.d/php-fpm-81 restart

# 4. 重载 Nginx
nginx -s reload

# 5. 查看 PHP-FPM 状态
/etc/init.d/php-fpm-81 status

# 6. 检查 PHP 错误日志
tail -f /www/server/php/81/var/log/php-fpm.log

# 7. 检查 Nginx 错误日志
tail -f /www/wwwroot/你的网站目录/logs/error.log
